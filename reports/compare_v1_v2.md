# 병뚜껑 유무 검사 — v1 vs v2 비교

## 데이터
| 세트 | 장수 | 구성 | 용도 |
|---|---|---|---|
| test | 24 | 뚜껑 있음 12 (검은 8 · 흰 4) / 없음 12 · 밝게 12 / 어둡게 12 | v1 분석, v2 기준값 결정 |
| holdout | 8 | 뚜껑 있음 4 (검은 2 · 흰 2) / 없음 4 · 모두 밝게 | 기준값 결정에 쓰지 않은 새 사진 → 진짜 성능 |

- 공통: 폭 1000 리사이즈 → ROI (x=90, y=240, w=800, h=800)
- 파일 이름 = 정답: `cap_{on|off}_{black|white|none}_{bright|dark}_NN.png`

## 방법
| 버전 | 파이프라인 | 판정 |
|---|---|---|
| v1 (수업 방식) | Gray → Otsu(BINARY_INV) → Morphology Open·Close 3×3 → Area Ratio | ratio ≥ 0.3608 → OK |
| v2 (개선) | Gray → 평균 밝기 검사 → CLAHE(3.0, 8×8) → Sobel 세로/가로 엣지 비율 | 평균 밝기 < 50 → RETAKE, ratio ≥ 0.67 → OK, 아니면 NG |

v2 아이디어: 뚜껑 옆면 줄무늬 = **세로선**, 뚜껑 없을 때 보이는 병 나사산 = **가로선** → 뚜껑 색과 상관없는 특징.

## 결과
| | test 24장 | holdout 8장 | 뚜껑 없는데 통과 (위험) | 정상인데 불량 (덜 위험) |
|---|---|---|---|---|
| v1 | 13/24 (54%) | 5/8 (62.5%) | 3건 | 0건 |
| v2 | 12/12 + RETAKE 12 | 5/8 (62.5%) | **0건** | 3건 |

> test의 v2 점수는 기준값(0.67)을 이 24장으로 정했기 때문에 실제보다 좋게 나온 값이다. 성능 비교는 holdout 기준으로 한다.

**핵심:** 정확도는 5/8로 같지만, v2는 불량품을 통과시키는 위험한 오류를 3건 → 0건으로 줄였다. 검사에서는 정확도보다 오류의 종류가 더 중요하다.

## 원인 분석
1. **v1은 '어두운 픽셀 양'을 잰다.** BINARY_INV라 어두운 곳을 물체로 센다 → 검은 뚜껑만 맞힘 (test 검은 뚜껑 8/8, 흰 뚜껑 2/4, 뚜껑 없음 3/12).
2. **어두운 사진은 판정 불가.** 평균 밝기 10~39로 사람 눈에도 거의 안 보임 → v1에서는 노이즈까지 물체로 잡혀 '뚜껑 없음'도 통과. v2는 RETAKE(재촬영)로 분리.
3. **v2 holdout 실패 3장 (모두 정상 → 불량).**
   - 촬영 위치·거리가 test와 달라 고정 ROI 안에 병 목(가로선)이 섞임
   - 줄무늬 없는 매끈한 검은 뚜껑 → '세로선' 가정 자체가 맞지 않음
4. **시도했지만 실패한 것:** Canny(50,150) 엣지 비율 → 거의 모든 사진에서 0 (해상도가 낮은 원본을 키워서 경계가 흐림).

## 한계와 다음 단계 (v3)
- 기준값을 24장으로 정해 여유가 작음 (어두운 사진에서 off 0.665 vs on 0.669)
- 고정 ROI는 촬영 위치가 바뀌면 깨짐 → **v3: 폰 실시간 화면에 가이드 박스 표시 + 여러 프레임 다수결**
- 대상 고정: 줄무늬 있는 뚜껑 1종 (Rule 기반 검사는 제품마다 기준을 따로 세팅)
- v3 기준값은 Calibration 사진으로 정하고, 새 Test 사진으로만 성능 보고
