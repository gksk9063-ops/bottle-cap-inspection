## 버전별 방법
| 버전 | ROI | 특징 / 판정 |
|---|---|---|
| v1 (수업 방식) | 고정 (90, 240, 800, 800) | Gray → Otsu(BINARY_INV) → Morphology → Area Ratio ≥ 0.3608 → OK |
| v2 | 고정 (같음) | 평균 밝기 < 50 → RETAKE · CLAHE → Sobel **세로/가로 엣지 비율** ≥ 0.67 → OK |
| v3 | **자동 ROI** | CLAHE → Sobel 엣지 → 병 실루엣 → 맨 윗부분 폭 w 기준으로 (1.2w × 1.1w) 자르기 · 비율 ≥ **0.52** → OK (Calibration 32장) |
| v3.1 | 자동 ROI | v3 + **기울기 검사**: 실루엣 중심선 기울기 > 12° → RETAKE |

v2 아이디어: 뚜껑 옆면 줄무늬 = 세로선, 뚜껑 없을 때 보이는 병 나사산 = 가로선 → 뚜껑 색과 상관없는 특징.

> v3.1은 final 결과를 보고 만든 규칙이라 final 점수는 참고용이며, 폰 실시간 시연(v4)에서 다시 검증한다.

## 버전마다 찾은 문제 → 다음 버전의 개선
1. **v1 → v2:** v1은 '어두운 픽셀 양'을 재서 검은 뚜껑만 맞힘 (test 검은 8/8 · 흰 2/4 · 없음 3/12). 어두운 사진(평균 밝기 10~39)은 노이즈까지 물체로 잡혀 '뚜껑 없음'도 통과 → v2: 색과 무관한 엣지 방향 특징 + 어두우면 RETAKE.
2. **v2 → v3:** holdout에서 정상인데 불량 판정 3건. 촬영 위치·거리가 바뀌면 고정 ROI 안에 병 목(가로선)이 섞이고, 줄무늬 없는 뚜껑도 있음 → v3: 병 실루엣을 찾아 ROI를 자동으로 맞춤. (Canny 엣지 비율도 시도했으나 저해상도라 거의 0 → 실패)
3. **v3 → v3.1:** final의 유일한 실패 = 30° 기울어진 병 → 나사산이 대각선이 되어 '세로선'으로 계산됨 → 뚜껑 없는데 통과. → v3.1: 기울어진 병은 판정하지 않고 RETAKE.
4. **자동 ROI 개발 중 해결한 문제:** test 사진 위쪽 검은 띠 · 배경 밝기 그라데이션(140→240) → 밝기 차이 대신 엣지만 사용 / 흰 뚜껑의 약한 경계 → 엣지 전에 CLAHE.
